# Idea Board

A suggestion box with voting, built with Laravel, Livewire and Filament.

## Demo logins

Run `php artisan migrate:fresh --seed` to load the demo data. Every account uses the password `password`.

| Role | Email |
|---|---|
| Employee | `employee@demo.test` |
| Reviewer | `reviewer@demo.test` |
| Admin | `admin@demo.test` |
